# 复盘加个股与自选股：往下走一层

状态：设计已定，2026-09-17 实现（用户子项目 A）

## 一、目标

复盘现在只到板块层面（涨停/连板/炸板/情绪周期/题材热点/龙虎榜/板块资金流），再往下一层：
从板块资金流与涨幅榜里挑出当日的个股线索，给每只补基本面、财务、舆情、驱动与风险；
自选股走同一套字段。**不给买卖点**（那是子项目 B 的事，价位由三周期选股与自选股买卖点给）。

## 二、为什么不复用现有 AI

复盘已有的五个分析师是**板块视角**（情绪面、资金面、题材、龙虎榜、龙头梯队），它们的输出是
盘面判断，不是个股档案。个股那一层要的是「这只股今天为什么被看到、它的基本面与财务是什么状态、
有什么消息、赌的是什么、风险在哪」，输入输出都不一样，所以单独一段、单独一次调用。
把个股塞进分析师提示词会让两边都变浅，而且会把板块研报的 token 预算吃掉。

## 三、挑哪些股（透明、可解释、不打分）

三路来源，各自带理由标签，去重后取前 `STOCK_N`（默认 8）只：

| 来源 | 取法 | 理由标签 |
|---|---|---|
| 板块资金流 | `fetch.sector_flow("concept")` 前 3 个板块，取当日涨停池里属于该板块的成员；没有匹配则取该板块市值前 2 只 | 板块资金流入第 N |
| 连板梯队 | 涨停池按 `limit_days` 降序（同高度按封单额）前 3 | N 连板 |
| 龙虎榜 | 当日龙虎榜净买额前 2（且涨幅为正） | 龙虎榜净买 X 万 |

不打分、不算权重：理由是给用户看的，谁入选一眼能查。这是刻意的——个股层面的因子没有历史验证
（复盘的个股数据只有当日快照），按 PITFALLS #1，验不了的就不装成有依据的分数。

## 四、每只补什么数据

| 字段 | 来源 | 说明 |
|---|---|---|
| 行情与估值 | `ds.tencent_quote`（批量一次） | 现价、涨跌、换手、PE、PB、市值、1 手成本 |
| 财务 | `fundamentals_store.latest_map`（本地面板，覆盖 99%） | 最新报告期的营收与利润同比 |
| 舆情 | `news_store.query(code=...)`（本地 L2 新闻库，滚动 1 年） | 最多 3 条标题，零网络 |
| 板块归属 | `universe_store.sectors_map` | 申万一级/二级 |
| 资金 | `screening._metrics_of`（新浪 MoneyFlow，并发） | 主力 5 日 / 20 日净流入 |
| 龙虎榜 | 已取的 `lhb` 列表命中 | 上榜原因与净买额 |

全部是**已有数据面的复用**，没有新数据源，没有新密钥。

## 五、输出契约（白名单，且没有价位）

一次 `v4-flash` 调用（成本与五个分析师同档），返回 JSON 数组，每项只收这些键：

```
code, name, sector, tagline（一句话它今天为什么值得看）,
fundamentals（基本面：主营与行业地位一句）,
financials（财务变化：营收/利润同比与拐点，只据给定数字）,
news（舆情：消息面一到两句，无消息就写「当日无显著消息」）,
driver（驱动：赌的是什么逻辑）,
risk（风险：这条逻辑最可能怎么失败）,
watch（盯什么：后续看哪个信号能验证或推翻）
```

**价位类字段一律丢弃**（`entry_lo/hi`、`exit_lo/hi`、`stop`、`target`、`buy`/`sell` 这类键与
正文里的价格区间都不落盘）。同 `picks_levels` 的做法：模型返回后按白名单重建对象，
不信任返回结构。买卖点归 B，这里越界会让两处结论互相打架。

## 六、公开块与个人块

- **公开块**：进复盘 envelope 的 `stocks` 字段（`data/review/<date>.json`），只含全市场标的，
  不含任何个人数据。复盘本体（硬指标 + 五分析师 + 文稿）失败或降级不受它影响，反过来也一样。
- **个人块**：自选股那一层按人隔离，落在 `data/users/<uid>/review_stocks.json`，按交易日缓存。
  公开复盘里绝不会出现任何人的自选股（多用户下的硬约束：公开数据与个人数据不能混在一个文件里）。

## 七、跑法与成本

- 公开块：`pipeline._run_locked` 在 AI 段之后顺带生成（仍在同一次持锁内），失败只记 warning。
- 个人块：调度进程在公开复盘跑完后，对每个有自选股的账号各生成一次；页面也有「生成」按钮
  走 `/api/review/stocks/run`，`force` 可重跑。
- 成本：公开 +1 次 flash，每个有自选股的账号 +1 次。都走 `ratelimit` 的预算门
  （公开记 `fleet`，个人记本人）。

## 八、明确不做

- 不给买卖点、不给目标价、不给仓位建议（归子项目 B）。
- 不做个股择时与打分排序（没有历史验证的分数就是拍脑袋）。
- 不引入新数据源（新浪/腾讯/本地库够用）。
- 不把持仓股混进「自选股」那一层：持仓的买卖建议走 `/api/recommend/position`，口径不同不混。
