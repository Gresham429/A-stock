# 提示词库（templates/prompts/）

蒸馏自 [PA_Agent](https://github.com/rosemarycox5334-debug/PA_Agent) 的 Al Brooks 价格行为体系，
改写为**A股波段/持仓分析**可用的框架，喂给看板的 DeepSeek 做选股/持仓/大盘研判。

## 文件
- `系统提示词-价格行为分析框架.md`：核心系统提示词（人设 + 交易者方程 + 禁令 + 8 状态 + 分析哲学）。归档参考。
- 这些是**静态归档**；实际注入 AI 的是**可编辑的规则库**（`rules_store.py` / 看板「📐 规则」）。

## 与规则库的关系
- **规则库**（`data/rules.db`，看板可增删改）= 由本框架蒸馏出的 ~55 条规则卡，**启用中的**会被 `app._ai_web_context` 注入每次 AI 分析，让看板 AI 按此框架给意见。
- 想改 AI 遵循的规则 → 在看板「📐 规则」里 编辑/停用/新增，不用改这里的 .md。
- 本目录只作**来源与全文参考**；改这里的 .md 不会自动改变 AI 行为（AI 只读规则库）。

## 与 PA_Agent 的差异（A股适配）
- PA_Agent 面向**日内价格行为交易**（逐 K、三价下单、MT5/TradingView）；本看板是**A股波段/持仓**，故蒸馏为**分析框架**而非日内下单指令。
- **剔除了「不依赖成交量」**这条——A股看板要用主力资金/成交额，与之冲突。
- 保留可迁移精华：周期状态识别、趋势/通道、区间、K线信号、止损止盈原则、纪律禁令、交易者方程。
